Devin Desktop은 무엇인가요?
Devin Desktop은 Windsurf의 새 이름입니다. Windsurf의 IDE 기반 위에, 모든 에이전트를 한곳에서 관리하는 커맨드 센터를 더했습니다. Agent Command Center(Spaces, 칸반 보기, 멀티 에이전트 관리)가 전면에 나오고, 익숙한 IDE 기능도 그대로 모두 쓸 수 있습니다.
Read the announcement →
Windsurf에서 Devin Desktop으로 어떻게 업그레이드하나요?
Devin Desktop은 일반 자동 업데이트로 설치되므로 요금제, 가격, 확장 프로그램, 설정이 모두 자동으로 이어집니다. 최신 Devin Desktop은 다운로드 페이지에서도 받을 수 있습니다.
업데이트하면 잃는 게 있나요?
IDE, 확장 프로그램, 워크플로, 설정, 진행 중인 작업이 모두 그대로 남고 업데이트할 때 전부 옮겨집니다. 바뀌는 건 이름과 브랜딩뿐입니다.
