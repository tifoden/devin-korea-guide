자주 묻는 질문

Devin CLI는 무엇인가요?
내 터미널에서 로컬로 돌아가는 Devin입니다. 내 저장소, 내 셸, 내 도구를 그대로 씁니다. 내 컴퓨터 없이 작업을 이어 가고 싶으면 세션을 Devin Cloud로 넘기면 됩니다.
문서 읽기 →
Devin Fusion은 무엇인가요?
Devin CLI의 멀티 모델 하네스입니다. 최상위 리드 모델이 판단과 중요한 수정을 맡고, 저렴한 보조 모델이 별도 컨텍스트에서 탐색, 파일 읽기, 테스트 실행을 맡습니다.
Read about how Fusion works →
Devin Cloud로 넘기기는 어떻게 동작하나요?
어느 세션에서든 /handoff를 실행하세요. 같은 맥락 그대로 Devin Cloud로 옮겨 가서 계속 일하고, 나중에 웹 앱이나 Devin Desktop에서 이어 볼 수 있습니다.
Claude Code나 Codex와는 무엇이 다른가요?
그 도구들은 각각 한 회사의 모델에 묶여 있습니다. Devin CLI는 Anthropic, OpenAI, Google, Cognition, 오픈 웨이트 모델을 모두 쓰고, Fusion으로 조합하며, 세션을 Devin Cloud로 넘길 수 있습니다.
쓰던 설정을 그대로 쓸 수 있나요?
네. AGENTS.md 규칙, MCP 서버, Claude Code 플러그인(스킬, 훅, 하위 에이전트 프로필)을 그대로 불러옵니다.
Extensibility docs →
어떤 플랫폼을 지원하나요?
macOS, Linux, Windows를 지원합니다. 위의 한 줄 스크립트로 설치하세요.
